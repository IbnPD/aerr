### 4. Project Description

I built a fully autonomous crypto operations agent powered by Hermes Agent (Claude-based) that manages a fleet of 390 cryptocurrency wallets across 5 blockchain networks (EVM, Solana, Bitcoin, SUI, Aptos). The core problem it solves: manual multi-chain wallet management is impossible at scale — monitoring balances, executing time-sensitive NFT mints, and coordinating cross-chain operations require 24/7 automation with sub-second response times.

The architecture uses a multi-agent orchestration pattern: a primary Hermes Agent handles task decomposition and decision-making, delegates parallel workloads to leaf subagents for concurrent execution across chains, and maintains encrypted credential storage with on-demand decryption workflows. Key capabilities include: automated competitive NFT hunting with rate-limited parallel minting across 100+ EVM wallets simultaneously, real-time gas estimation and transaction optimization, smart contract interaction with simulation-first execution, and self-healing retry logic with exponential backoff for RPC failures.

The system integrates with GitHub for CI/CD automation, Telegram for real-time notifications and command interface, and multiple blockchain RPC providers for redundancy. It processes complex multi-step workflows including token swaps, bridge operations, staking, and claim rewards — all orchestrated through a single conversational interface with human-in-the-loop approval for high-value transactions.
